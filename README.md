# CRM Data Migration & Validation Project

## Project Overview

This portfolio project demonstrates an end-to-end migration of synthetic contact records from spreadsheet based source files into a standardized CRM ready dataset.

The project includes:

- Source data profiling
- Data cleansing
- Duplicate detection
- Source-to-target mapping
- SQL validation
- Exception handling
- Migration testing
- Source-to-target reconciliation

## Business Scenario

An organization is replacing spreadsheet based contact management with a CRM platform. Existing contact data contains duplicate records, missing values, inconsistent formatting, and invalid data that must be corrected before production deployment.

## Tools Used

- SQL
- Microsoft Excel
- CSV
- GitHub
- ETL and data migration concepts

## Migration Workflow

1. Extract source records from CSV.
2. Profile source data quality.
3. Identify duplicates and invalid records.
4. Standardize and cleanse accepted records.
5. Map source fields to CRM target fields.
6. Prepare an import ready CSV.
7. Validate migrated records.
8. Reconcile source and target control totals.

## Simulated Results

- Synthetic source records analyzed
- Duplicate and invalid records identified
- Cleaned CRM ready dataset produced
- Rejected records documented with reasons
- Source and target totals reconciled
- Zero unexplained record variance

## Important Note

All records and project results in this repository are synthetic and were created solely for portfolio demonstration purposes.
